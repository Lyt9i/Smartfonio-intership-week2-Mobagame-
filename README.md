# MOBA Autobattler

Прототип автобатлера в стиле MOBA на Unity: две команды крипов автоматически сражаются друг с другом на арене, а игрок выбирает сторону и усиливает её, вручную докупая юнитов за очки.

## Геймплей

1. В начале игры показывается экран выбора команды — **красная** или **синяя**.
2. После выбора игрок получает ** стартовые очки**.
3. Выбранная сторона перестаёт спавнить юнитов автоматически — теперь игрок сам решает, кого и когда призывать, тратя очки.
4. Вражеская сторона продолжает генерировать юнитов автоматически через равные промежутки времени.
5. Юниты сами находят ближайшего врага, сближаются на дистанцию атаки своего оружия и дерутся; если врагов рядом нет — идут к вражеской базе.
6. За убийство юнита команде начисляются очки (см. `KillRewardListener`).
7. Цель — уничтожить `Base` противника.
## Управление

| Действие | Клавиша/кнопка |
|---|---|
| Движение камеры | `W` `A` `S` `D` (вперёд/влево/назад/вправо относительно направления камеры) |
| Ускоренное движение камеры | Зажать `Shift` во время движения |
| Поворот камеры | Зажать **ЛКМ** и двигать мышью (курсор скрывается и фиксируется на время поворота) |
| Выбор команды | Клик по кнопке **Red** / **Blue** на стартовом экране |
| Покупка юнита | Клик по кнопке **Melee** / **Tank** / **Range** на панели покупки (списывает очки согласно стоимости юнита) |

Клики по UI не влияют на камеру — `CameraController` игнорирует зажатие ЛКМ, если курсор находится над интерфейсом (кнопки, панели).

## Типы юнитов

| Тип | Стоимость | Особенность |
|---|---|---|
| Melee | 10 | Малая дальность атаки, дерётся вплотную |
| Range | 15 | Большая дальность атаки, держит дистанцию |
| Tank | 20 | Больше здоровья, ниже урон и скорость |

Каждый тип существует в виде отдельного префаба для красной и синей команды (`Melle_Red`, `Melle_Blue`, `Tank_Red`, `Tank_Blue`, `Range_Red`, `Range_Blue`), баланс характеристик (здоровье, урон, дальность атаки, скорость, стоимость) настраивается прямо в инспекторе, без правки кода.

## Структура скриптов

### Игровой цикл и данные о матче
- **`GamePlayManager`** — синглтон, хранит список всех юнитов на сцене, обрабатывает их регистрацию/удаление, отдаёт вражеские базы по команде.
- **`GameSession`** — статический класс, хранит id команды игрока (`PlayerTeamId`) и событие `onTeamSelected`, на которое подписываются UI и фабрики.
- **`ScoreManager`** — синглтон, хранит очки каждой команды, умеет начислять (`AddPoints`) и списывать (`TrySpend`).

### Юниты
- **`Unit`** / **`MovebleUnit`** — базовые классы юнита и юнита с передвижением (`NavMeshAgent`).
- **`Crip`** — крип: ищет ближайшую цель, сближается до дальности атаки своего оружия и останавливается (атаку берёт на себя `AutoAttacker`), либо идёт к вражеской базе, если целей рядом нет.
- **`Base`** — база команды, конечная цель для уничтожения.
- **`Health`** — здоровье юнита.
- **`TeamTag`** — принадлежность объекта к команде (1 — красная, 2 — синяя).
- **`Weapon`** / **`WeaponHandler`** — параметры оружия (урон, дальность, интервал атаки) и его обработка.
- **`AutoAttacker`** — автоматическая атака цели в радиусе поражения.
- **`TargetController`** / **`AutoTargetController`** — поиск и хранение текущей цели юнита.
- **`KillRewardListener`** — начисляет очки команде за убийство вражеского юнита.

### Спавн
- **`CripFactory`** — фабрика юнитов одной команды:
  - автоматически спавнит юнитов через `_timeDelay`, пока эта команда не выбрана игроком;
  - хранит список `CripOption` (префаб + стоимость) для ручного спавна игроком через `TrySpawnByPlayer(index)`.

### UI
- **`TeamSelectionUI`** — экран выбора команды, включает игровую сцену и начисляет стартовые очки после выбора.
- **`CripShopUI`** — панель с кнопками покупки юнитов (Melee/Tank/Range); сама находит нужную `CripFactory` по выбранной команде игрока.
- **`ScoreUI`** — отображение текущих очков обеих команд.

### Камера
- **`CameraController`** — управление камерой (вращение по зажатию ЛКМ), игнорирует клики по UI (`EventSystem.IsPointerOverGameObject`), чтобы не конфликтовать с интерфейсом.
